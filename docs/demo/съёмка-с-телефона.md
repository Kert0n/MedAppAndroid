# Съёмка показа с телефона

Сюжет играет человек, а не обход: камера живая, шторка настоящая, палец настоящий. От приложения
нужно одно — **стартовые условия**: состояния, которых перед камерой за две минуты не создать
(просроченная пачка, чужие брони, изменение в пути, отказ сервера по версии, лечение с нехваткой,
приёмы без ответа за прошлые дни). Их кладёт в базу посев
`app/src/androidTest/java/com/kert0n/medapp/tour/PhoneStage.kt`.

Сюжет и реплики — `docs/Final/Сценарий демонстрации.md` зонтичного репозитория.

## Что уже стоит на телефоне

| что | как |
|---|---|
| сборка | debug (release 1.1 снесена: посев работает только со своей подписью) |
| язык приложения | русский, задан отдельно от языка телефона |
| разрешения | уведомления и камера выданы заранее — диалоги не полезут в кадр |
| связь | **режим полёта включён** |
| мир | посеян; приложение **ни разу не открывалось** — вход ваш |
| тема | ваша, какой была |

## Перед каждым дублем — пересев

Мир пересевается одной командой, **без связи и без новой учётной записи**: учётные данные лежат
отдельно от базы, поэтому стирается только база.

```bash
adb -s 54121FDAS000R7 shell am force-stop com.kert0n.medapp &&
adb -s 54121FDAS000R7 shell run-as com.kert0n.medapp rm -f databases/medapp.db databases/medapp.db-shm databases/medapp.db-wal &&
adb -s 54121FDAS000R7 shell am instrument -w -e stage true -e due 10 -e class com.kert0n.medapp.tour.PhoneStage com.kert0n.medapp.test/com.kert0n.medapp.HiltTestRunner
```

`-e due 10` — **через сколько минут придёт напоминание**. Ставьте столько, за сколько дойдёте до
сцены со шторкой: приём «Цетрин при аллергии» встанет на это время, приложение само поставит
будильник и само покажет уведомление с ответами. Дошли раньше — подождите; опоздали — пересейте.

После пересева **приложение не открывайте**: при входе оно показывает приёмы без ответа за прошлые
дни, и это первая сцена.

## Порядок съёмки

1. **Связь выключена** (режим полёта) — и остаётся выключенной весь сюжет. Мир выдуман, и
   очередь, увидев сеть, повезёт его боевому серверу: чужие брони и отказ сервера настоящими
   не станут, а на сервере появится мусор.
2. Пересев командой выше.
3. Включите запись экрана телефона и **откройте приложение** — вход показывает пропущенные приёмы.
4. Играйте сюжет по сценарию: аптечки → «Домашняя» с просроченной → карточка упаковки → лечение с
   нехваткой → источники (подключить «Нурофен Экспресс» поиском и перетащить наверх) → день →
   карточка пункта → **шторка с напоминанием** → «Дача» с чужими бронями, «Изменением в пути» и
   отказом сервера → приглашение → отчёты.
5. Сцену **сканирования снимайте отдельным куском** — она требует связи, а сюжет её не терпит:

   ```bash
   adb -s 54121FDAS000R7 shell pm clear com.kert0n.medapp &&
   adb -s 54121FDAS000R7 shell cmd connectivity airplane-mode disable
   ```

   Дальше руками: откройте приложение (оно заведёт учётную запись), заведите аптечку, «Сканер»,
   наведите на DataMatrix настоящей коробки — форма откроется заполненной ответом реестра. Это и
   есть та сцена, которой в записи с эмулятора быть не могло: виртуальная камера кода не видит.

6. Склейка — `ffmpeg -f concat`, как в `README.md` рядом.

## Когда снимете

Телефон возвращается к обычной жизни так:

```bash
adb -s 54121FDAS000R7 shell pm clear com.kert0n.medapp &&
adb -s 54121FDAS000R7 shell cmd connectivity airplane-mode disable
```

и установкой release-сборки из [последнего релиза](https://github.com/Kert0n/MedAppAndroid/releases/latest)
поверх debug — она ставится только после `adb uninstall com.kert0n.medapp`, подписи разные.

## Что лежит в посеянном мире

- **Аптечки:** «Домашняя» (в ванной, верхняя полка), общая «Дача» (кухонный шкаф, трое участников),
  пустой «Рюкзак».
- **Коробки:** просроченный «Парацетамол», истекающий «Ибупрофен», «Нурофен» на лечении, «Нурофен
  Экспресс» со сроком ближе — его и подключают в кадре, «Цетрин», «Амброксол», «Амоксиклав»; на
  «Даче» — «Аспирин», «Но-шпа» и «Смекта» с изменением в пути.
- **Лечения:** «Нурофен от спины» — идёт, с нехваткой; «Цетрин при аллергии» — по нему придёт
  напоминание; «Витамин D» — черновик.
- **Очередь:** три строки в пути, среди них отказ сервера по версии.
