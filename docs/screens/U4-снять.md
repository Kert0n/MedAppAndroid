# U4 — что снять руками

Снимки делает владелец (решение 2026-09-16). PR оставляет **список**, а не картинки.

Куда класть: `docs/screens/<AVD>/<NN-экран>/<состояние>.png`, `screencap` как есть, без обработки.
Устройства — `Sm29` (API 29, 360×640 dp) и `BigScaled` (540 dpi, шрифт ×1.3, 398×887 dp); на
`BigLatest` не нужно. Тёмная тема и поворот — **только** на экране 12.

Перед проходом: `am force-stop` + `am start`, **без `pm clear`** (он стирает учётные данные).
Чтобы день был не пустым, нужно идущее лечение с двумя приёмами в день.

## Свои экраны U4

| экран | состояние | что должно быть видно |
|---|---|---|
| `12-day` | `empty` | заголовок с датой и словом «сегодня», «На этот день ничего не назначено» |
| `12-day` | `filled` | пункты по времени: время · лечение · доза · коробка; у неотвеченного — «Пропустил» и «Принял» |
| `12-day` | `answered` | принятый — «принят в 09:12» вместо кнопок; **пропущенный — слово „пропущен“ и всё же „Принял“** |
| `12-day` | `also` | полка «Ещё в этот день»: разовый приём и «ожидается» за окном календаря, без действий |
| `12-day` | `tomorrow` | свайп вперёд: «завтра» с той же вёрсткой |
| `12-day` | `dark`, `landscape` | тёмная тема и поворот — **только здесь** |
| `18-intake-card` | `planned` | назначенное строкой, выбор коробки из источников, доза, день и час; подвал «Принял», «Пропустил», «Отмена» |
| `18-intake-card` | `questions` | один диалог со списком: «Коробка просрочена…», «Приём заденет занятое…», кнопка «Всё равно принял» |
| `18-intake-card` | `answered` | «принят в …», полей ввода и кнопок ответа нет, коробка строкой |
| `18-intake-card` | `gone` | «Этого приёма больше нет» |
| `19-intake-history` | `filled` | сверху последнее: день · время · доза · лечение (или коробка) · чем кончилось |
| `19-intake-history` | `empty` | «Отсюда ещё ничего не принимали» |
| `19-intake-history` | `after-the-box` | история коробки, которой больше нет: строки на месте |
| `10-unplanned-intake` | `questions` | тот же диалог вопросов, что и на 18 |
