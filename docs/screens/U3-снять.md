# U3 — что снять руками

Снимки делает владелец (решение 2026-09-16): автоматический проход синтетическими нажатиями
спотыкается о меню словаря и клавиатуру, и цена его выше пользы. PR оставляет **список**, а не
картинки.

Куда класть: `docs/screens/<AVD>/<NN-экран>/<состояние>.png`, `screencap` как есть, без обработки.
Устройства — `Sm29` (API 29, 360×640 dp) и `BigScaled` (540 dpi, шрифт ×1.3, 398×887 dp); на
`BigLatest` не нужно. Тёмная тема и поворот — **только** на экране 16.

Перед проходом: `am force-stop` + `am start`, **без `pm clear`** (он стирает учётные данные).

## Свои экраны U3

| экран | состояние | что должно быть видно |
|---|---|---|
| `13-courses` | `empty` | «Лечений пока нет» и подсказка про заметку |
| `13-courses` | `filled` | три полки: «Идут», «Черновики» (с заметкой второй строкой), «Завершены»; у нехватки — значок и «не хватает N приёмов с …» |
| `14-course-card` | `running` | первым обеспечение («нужно N · обеспечено M» либо «обеспечен до …»), назначение словами, источники, пункты по датам |
| `14-course-card` | `cancel-dialog` | вопрос «Отменить лечение?» с последствиями |
| `14-course-card` | `cancelled` | плашка «Отменён …», источников нет, история приёмов на месте |
| `15-course-form` | `new` | пустой черновик: «обязательно» только под названием |
| `15-course-form` | `filled` | форма выпуска выбрана и **единица встала сама**; подвал с «Сохранить», «Начать лечение», «Отмена» |

| `16-course-sources` | `empty` | «Пачек пока нет — подключите первую» |
| `16-course-sources` | `stack` | две коробки, ползунки и точные поля, сводка обеспечения |
| `16-course-sources` | `unsaved` | «Правка не записана: обеспечение пересчитается после „Сохранить“» |
| `16-course-sources` | `detach-dialog` | «Отвязать пачку?» с последствиями |

| `16-course-sources` | `dark`, `landscape` | тёмная тема и поворот — **только здесь** |

| `17-source-picking` | `no-prescription` | черновик без дозы и формы: «Сначала укажите дозу и форму лечения» |

## Чужие экраны, которые U3 задел

Общие составляющие (`ui/Form`, `ui/QuantityField`, `DateField`) изменили вид форм, поэтому их
снимки из U1 устарели:

| экран | состояние | почему |
|---|---|---|
| `03-med-kit-form` | `filled` | действия стали подвалом |
| `07-package-form` | `filled` | количество и единица **в одной строке**; подвал |
| `07-package-form` | `typing` | подвала не видно, пока набирают |
| `08-package-edit` | `filled` | то же |
| `09-recount` | `filled` | подвал с «Записать» |
| `06-package-card` | `filled` | даты покупки и вскрытия: поле открывает календарь нажатием целиком |
